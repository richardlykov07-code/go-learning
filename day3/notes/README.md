## 📚 Справочник: циклы в Go

### 4 формы `for`

```go
// 1. Классический (счётчик)
for i := 1; i <= 10; i++ { }

// 2. «Пока условие» (заменяет while)
for x < 10 { }

// 3. Бесконечный
for { }

// 4. Range — обход коллекций
for i, v := range nums { }
```

### Управление

- `break` — выйти из цикла совсем
- `continue` — пропустить итерацию
- `break label` — выйти из внешнего цикла

### Range для разных типов

```go
// Слайс
for i, v := range nums { }      // i — индекс, v — значение
for _, v := range nums { }      // только значения
for i := range nums { }          // только индексы

// Мапа
for k, v := range m { }

// Строка
for i, r := range s { }          // i — байт, r — руна (int32)

// Числа (Go 1.22+)
for i := range 5 { }             // 0, 1, 2, 3, 4
```

### Важно: `v` в `range` — копия

```go
for _, v := range nums {
    v *= 2          // меняет КОПИЮ, не оригинал
}

for i := range nums {
    nums[i] *= 2    // ✅ меняет оригинал
}
```

## 📚 Справочник: слайсы

### Создание

```go
nums := []int{1, 2, 3}              // литерал
nums := make([]int, 5)              // длина 5, все 0
nums := make([]int, 0, 10)          // длина 0, capacity 10
```

### `len` vs `cap`

- `len(s)` — сколько занято
- `cap(s)` — сколько выделено

### `append`

```go
nums = append(nums, 4)               // добавить один
nums = append(nums, 4, 5, 6)         // добавить несколько
nums = append(nums, other...)        // добавить слайс
```

**Правило:** всегда `nums = append(nums, ...)` — переприсваивай!

**Как работает:**
- Если `len < cap` — пишет в тот же массив, возвращает слайс с `len+1`.
- Если `len == cap` — выделяет новый массив в 2 раза больше, копирует, возвращает.

### Срез слайса

```go
nums[1:4]    // с 1 включительно до 4 НЕ включительно
nums[:3]     // с начала до 2
nums[3:]     // с 3 до конца
```

**Срез не копирует данные** — он смотрит в тот же массив. Изменение среза меняет оригинал.

### Копия слайса

```go
sub := make([]int, 3)
copy(sub, nums[1:4])    // копирует
```

## 📚 Справочник: мапы

### Создание

```go
m := make(map[string]int)
m := map[string]int{"Alice": 30, "Bob": 25}
```

**Никогда `var m map[K]V` без `make`** — это nil-мапа, запись паникует.

### Операции

```go
m["Alice"] = 30              // добавить/изменить
v := m["Alice"]              // прочитать (zero-value, если нет)
v, ok := m["Alice"]          // прочитать + проверить наличие
delete(m, "Alice")           // удалить
len(m)                       // длина
for k, v := range m { }      // обход (порядок не определён)
```

### Идиома `ok`

```go
if v, ok := m[key]; ok {
    // ключ есть, работаем с v
} else {
    // ключа нет
}
```

**Почему два значения:** `m[key]` возвращает `0` (zero-value), если ключа нет. Ты не отличишь «есть ключ со значением 0» от «ключа нет». `ok` решает это.

### Мапа как «множество» (set)

```go
seen := make(map[int]bool)

if !seen[v] {
    // v ещё не видели
    seen[v] = true      // помечаем
}
```

`seen[v]` для несуществующего ключа возвращает `false` (zero-value). Не нужно `ok`.

## 📚 Справочник: `append` — почему переприсваивать

`append` **не меняет** существующий слайс. Он **возвращает новый**:

- Если места хватало (`len < cap`) — тот же массив, но новый слайс с `len+1`.
- Если места не хватало — новый массив (в 2 раза больше), копирование старых.

```go
nums := []int{1, 2, 3}
append(nums, 4)          // ❌ результат выброшен, nums = [1 2 3]
nums = append(nums, 4)   // ✅ nums = [1 2 3 4]
```

**Правило:** всегда `nums = append(nums, ...)`.

## 📚 Big-O: O(n) vs O(n²)

**Big-O** — как растёт время работы с размером данных.

| Обозначение | Что значит | Пример |
|-------------|-----------|--------|
| **O(1)** | Константное | `m[key]` в мапе |
| **O(n)** | Линейное | Один цикл по слайсу |
| **O(n²)** | Квадратичное | Вложенные циклы |
| **O(log n)** | Логарифмическое | Бинарный поиск |

### Сравнение

| n | O(n) | O(n²) |
|---|------|-------|
| 10 | 10 | 100 |
| 100 | 100 | 10 000 |
| 1000 | 1000 | 1 000 000 |
| 10 000 | 10 000 | **100 000 000** |

### Пример: поиск дубликатов

**Плохо (O(n²)):**
```go
for _, v := range nums {
    for _, r := range result {   // ← вложенный цикл
        if v == r { /* ... */ }
    }
}
```

**Хорошо (O(n)):**
```go
seen := make(map[int]bool)
for _, v := range nums {
    if !seen[v] {                // ← одна операция, O(1)
        // ...
        seen[v] = true
    }
}
```

**Правило:** если можно заменить вложенный цикл на мапу — **заменяй**.
